SCAN FLOW

毎日のスキャン手順

01
相場全体トレンド確認
日経225 or S&P500 の MA20 vs MA50 を比較
MA20 ＞ MA50 → 市場↑（強気） | MA20 ＜ MA50 → 市場⚠（警戒）
02
週足スキャン → 週足整合チェック
週足で MA5・MA10・MA20 が整列しているか確認
週足でも整列（整列2ペア以上）→ 週足↑ フラグ
03
日足スキャン（全銘柄）
各銘柄の 1年分のデータで 6本のMAを計算
MA5・MA10・MA20・MA50・MA100・MA200 の整列を判定
04
スコアリング → ランキング
整列・上昇・出来高などを点数化してGC/S/A/B/Cに分類
05
メール送信 + ダッシュボード更新
結果をCSVとスクリーンショットで自動配信。GitHub Pagesも更新

RANKING

ランク判定基準

GC
ゴールデンクロス確定
本物のGC = 整列が整った状態でのクロス
✅ MA5がMA10を上抜け（当日）
✅ MA整列が3ペア以上
例: ●●●○○ 以上 ＋ GC → 本物
例: ●○○○○ ＋ GC → GCランクにならない（短期のダマシ）
S
最高水準 スーパー銘柄
スコア 80点以上
●●●●● 完全整列 + 全MA上昇 → Sランク確定水準
A
優良 買い候補
スコア 60〜79点
●●●●○ 4ペア整列 + 大半が上昇 → Aランク水準
B
注目 様子見
スコア 40〜59点
●●●○○ 3ペア整列 → Bランク水準
C
弱い / 待機
スコア 39点以下
●●○○○ 以下 → トレンド未形成
FILTERS

勝率を高める4つのフィルター

📊
①週足整合フィルター +15点
週足チャートでもMA5・MA10・MA20が整列していれば、
「日足だけでなく週足でも上昇」→ スコア+15点
週足整列2ペア以上 → 「週足↑」表示
📈
②出来高フィルター +10点
当日の出来高 ÷ 直近20日平均 ≥ 1.5倍
→ 機関投資家が動いているサイン
出来高×1.5以上 → 「×2.1」など緑色で表示
🌏
③相場全体フィルター -20点（警戒時）
指数（日経225 / S&P500）のMA20 vs MA50を確認
市場が下降トレンドなら個別銘柄を減点
市場↑ → そのまま | 市場⚠ → 全銘柄スコア-20点
🎯
④押し目フィルター +15点
株価がMAの±2%以内で接触中 かつ 整列3ペア以上
→ 「押し目買い」の最高のタイミング
「押MA5」「押MA20」などで表示
