## 1. 基本戦略の考え方

中期上昇トレンドにある大型優良株に対し、**短期的な押し目で仕込み、トレンド継続を取りに行く**順張り戦略。スクリーニング（候補抽出）とエントリータイミングを分離して定義する。

- **時間足**：日足（Daily）
- **対象市場**：日本株（JP）、米国株（US）
- **想定資金規模**：1億円〜

## 2. 市場環境フィルタ（v3.0で追加・v3.1で強化）

### 2-1. 市場トレンドフィルタ（必須）

新規エントリーは、所属市場が上昇トレンドにある場合のみ実行する。

| 市場 | 基準指数 | 条件 |
|---|---|---|
| 日本株 | TOPIX | TOPIX終値 > TOPIX SMA(20) |
| 米国株 | S&P 500 (SPY) | SPY終値 > SPY SMA(20) |

**基準を満たさない場合**：既存ポジションは継続、**新規エントリー停止**。

### 2-2. ボラティリティフィルタ（必須）

| 指標 | 基準 | アクション |
|---|---|---|
| VIX | **28未満** | 通常運用 |
| VIX | **28以上35未満** | 新規エントリー停止、既存ポジションのみ継続 |
| VIX | **35以上** | 新規エントリー停止＋既存ポジションの利確検討 |

### 2-3. イベントフィルタ（必須）

| 状況 | アクション |
|---|---|
| 決算3営業日前〜決算翌営業日 | 該当銘柄は新規エントリー禁止 |
| FOMC・日銀政策決定会合の前営業日 | 新規エントリー慎重化（指値は浅く） |
| 米雇用統計・CPI発表前日 | 同上 |

## 3. スクリーニング条件（候補銘柄の抽出）

### 3-1. トレンド条件（必須）

- SMA(5) > SMA(10) > SMA(20)（上昇のパーフェクトオーダー）
- SMA(20) > SMA(60)（中期トレンドも上向き）
- 終値 > SMA(60)（中期トレンド上にあること）

### 3-2. 過熱感フィルタ（必須）

- RSI(14)：**40〜75**の範囲内
- 終値のSMA(20)からの乖離率：**+7%未満**
- 過熱組み合わせ除外：「RSI 65〜75」かつ「乖離率 +5%超」の組み合わせは過熱圏とみなし除外

### 3-3. 流動性条件（必須）

| 市場 | 基準 |
|---|---|
| 日本株 | 直近30日平均売買代金 **50億円以上** |
| 米国株 | 直近30日平均売買代金 **5億ドル以上** |

## 4. 対象銘柄ユニバース

### 4-1. 日本市場

- 時価総額 **2兆円以上**
- 客観基準：**TOPIX Core30 + TOPIX Large70** の構成銘柄を母集団とする
- 監視対象（例）：東京エレクトロン(8035)、アドバンテスト(6857)、信越化学工業(4063)、キーエンス(6861)、三菱重工(7011)、三菱UFJ(8306)、伊藤忠商事(8001)、クボタ(6326)、荏原製作所(6361)

### 4-2. 米国市場

- 時価総額 **2,000億ドル以上**
- 客観基準：**S&P 100** の構成銘柄を母集団とする（セクターは限定しない）
- 監視対象（例）：NVIDIA(NVDA)、Microsoft(MSFT)、Broadcom(AVGO)、Tesla(TSLA)

## 5. エントリー条件（タイミング判定）

スクリーニングを通過した銘柄に対し、以下のいずれかを満たした時点でエントリー候補とする。

### 5-1. 押し目パターン（優先）

- 終値が **SMA(5)を一時的に下抜けた後、再度終値ベースで上抜けた日**
- または、終値が **SMA(10)±1%以内にタッチして陽線で反発**した日

### 5-2. 浅押しパターン

- 終値が SMA(5) の上にあり、かつ SMA(5) からの乖離が **+2%以内**
- 直前2〜3営業日が陰線または小幅な調整局面であること

### 5-3. 指値の置き方

- 成行は使わない
- SMA(5) または SMA(10) の現値、もしくは直近3〜5営業日の安値を目安に指値
- **指値変更による追いかけ禁止**：押し目に到達せず上昇した場合、指値を上方修正してはならない

## 6. 資金管理・リスク管理

### 6-1. ポジションサイジング

- 1銘柄あたりの投入額：総資金の **10〜15%以下**
- 同時保有銘柄数：**3〜6銘柄**を目安に分散

### 6-2. セクター集中の上限（v3.0で細分化）

| セクター | 上限（総資金比） |
|---|---|
| 半導体・半導体製造装置 | 25% |
| 電線・電力インフラ | 15% |
| 防衛・重工 | 15% |
| 金融（銀行・証券・保険）| 20% |
| 商社 | 15% |
| その他単一セクター | 15% |

**合計で総資金の80%以下**（残り20%は現金または分散用バッファ）。

### 6-3. ポートフォリオ・カテゴリ分散（v3.1で追加）

銘柄を以下の2カテゴリに分類し、配分を管理する。

| カテゴリ | 定義 | 推奨配分 |
|---|---|---|
| **強トレンド型** | SMA(60)上向き、週足MACDプラス圏、明確な上昇継続中 | **60〜80%** |
| **反転初動型** | SMA(60)横ばい〜下向きから反発中、週足MACD改善中 | **20〜40%** |

**全銘柄が強トレンド型に偏ると、市場のセクター循環リスクに脆弱になる**ため、意図的な分散を行う。

### 6-4. 損切り基準（いずれか先に到達した時点で執行）

| 条件 | 内容 |
|---|---|
| ① テクニカル | 終値ベースで **SMA(20)を明確に下抜け**（1%以上の下抜けを目安）|
| ② 価格 | エントリー価格から **-7%** |
| ③ トレンド転換 | パーフェクトオーダーが崩れた（SMA(5) < SMA(10)）翌日の寄り |

**US株のみの特例**：パーフェクトオーダー崩壊が3営業日継続した場合に発動（一時的な崩れを許容）

### 6-5. 利確・トレーリング

- 含み益が **+10%** に到達した時点で建値に逆指値を移動（コスト割れ防止）
- それ以降は **SMA(10)割れ**でトレーリング決済
- RSI(14)が過熱した場合は半利確
  - 超大型株（時価総額10兆円超）：**RSI 80超**で半利確
  - 中型〜大型株（時価総額2〜10兆円）：**RSI 72〜75超**で半利確

## 7. 撤退条件テンプレート（v3.1で追加）

各銘柄でエントリー時に、以下の3条件を明確化する。これは6-4の損切り基準を**銘柄ごとに具体化**したもの。

### 7-1. 撤退条件テンプレ

```
銘柄：____________ (コード ____________)
エントリー指値：____________円
エントリー時の関連数値：
  - SMA(20)：____________円
  - 直近のサポートライン：____________円

撤退条件①：終値が SMA(20) を明確に下抜け（____________円割れ）
撤退条件②：エントリー価格から -7%（____________円）
撤退条件③：パーフェクトオーダー崩壊（SMA(5) < SMA(10)）
追いかけ禁止：指値到達せず上昇した場合、指値を上方修正しない
```

### 7-2. 特殊カテゴリ向け追加条件

**反転初動型銘柄**は通常の3条件に加え、以下を併用：
- 撤退条件④：直近の反発基点を割り込んだ場合（例：直近安値が1,950円なら1,940円割れで撤退）

## 8. 判定の透明性ルール（v3.1で追加）

スクリーニング・エントリー条件で**明確に判定が分かれた場合**の扱いを定義する。

### 8-1. 条件適合の3段階評価

| 評価 | 条件 | 推奨アクション |
|---|---|---|
| 🟢 完全適合 | スクリーニング全項目クリア＋エントリー条件該当 | 通常エントリー |
| 🟡 条件付き適合 | スクリーニング全項目クリアだが、エントリー条件未達（または指値位置がずれている）| **指値修正で対応**（エントリー条件に合わせる）|
| 🔴 不適合 | スクリーニング項目に1つでも不合格 | **エントリー禁止・取消** |

### 8-2. 「条件付き適合」の運用ルール

🟡 判定の場合：
1. 既存指値を、エントリー条件4-1/4-2に該当する価格に修正する
2. 修正できない場合（押し目が現値より下すぎる等）、待機または取消
3. **例外で残す場合は、その理由をログに残し、撤退条件を強化する**

### 8-3. 判定ログの記録（必須）

各銘柄判定時に以下を記録：

```
日付：____________
銘柄：____________ (____________)
判定：🟢 / 🟡 / 🔴
不合格項目：____________
アクション：エントリー / 指値修正（旧:_____ → 新:_____）/ 取消
備考：____________
```

## 9. 「やらない局面」リスト（v3.1で追加）

強いトレーダーほど休むのが上手い、という原則に基づき、明確に**新規エントリーを停止する局面**を列挙する。

### 9-1. 市場全体での停止条件

| 状況 | 停止期間 |
|---|---|
| TOPIX終値 < SMA(20) | 復帰まで |
| SPY終値 < SMA(20) | 復帰まで（US株のみ） |
| VIX ≥ 28 | 復帰まで |
| FOMC・日銀会合の翌営業日まで | イベント通過まで |
| 米雇用統計・CPI発表当日 | 発表後の落ち着きまで |

### 9-2. 個別銘柄での停止条件

| 状況 | 停止期間 |
|---|---|
| 決算3営業日前〜決算翌営業日 | 期間中 |
| 重要IR発表予定 | 発表翌営業日まで |
| 出来高急増（直近平均の3倍超）翌日 | 出来高が落ち着くまで（最低3営業日）|
| 噴き上げ急落型のチャート（前日比±5%超の不安定な値動きが2日続く）| 5営業日程度 |

### 9-3. 自分の状態での停止条件

| 状況 | 対処 |
|---|---|
| 直近3トレード連続で損切り | 1週間休む、ルール見直し |
| 月間損失が総資金の-3%超 | その月の新規停止 |
| 感情的になっている（怒り・焦り・興奮）| 24時間休む |
| 睡眠不足・体調不良 | 回復まで休む |

## 10. AIへの指示テンプレート

以下をそのまま渡せば動作するように指示文を明確化する。

```
【依頼内容】
以下の条件定義（波乗りトレード v3.1）に基づき、現在の市場で合致する銘柄を抽出してください。

【手順】
1. 市場環境フィルタ（TOPIX/SPY、VIX）を確認
   - 市場フィルタNG → 「現在は新規エントリー停止局面」と返答し終了
2. 「4. 対象銘柄ユニバース」の母集団から、
   「3. スクリーニング条件」の全項目を満たす銘柄をリスト化
3. 各銘柄について以下を併記
   - 現在値、SMA(5/10/20/60)、RSI(14)、SMA(20)乖離率
   - 「5. エントリー条件」のどのパターンに該当するか（5-1/5-2/該当なし）
   - カテゴリ分類（強トレンド型 / 反転初動型）
   - 推奨指値レンジ
   - 直近3営業日中の決算予定の有無
   - 撤退条件テンプレ（7-1）を埋めた形で提示
4. スクリーニング通過銘柄が10件を超える場合は、
   SMA(20)乖離率の小さい順（=押し目度合いが深い順）に上位10件を提示
5. 該当銘柄が0件の場合は「現在の市場環境では条件合致銘柄なし」
   と明示し、最も惜しい銘柄を3件、未達条件と併記して提示
```

## 11. 数値の感度分析と見直し（v3.1で追加）

本定義書の数値は**初期値**であり、市場環境や運用結果に応じて見直しを行う前提とする。

### 11-1. 見直しサイクル

| 項目 | 見直し頻度 | 見直し基準 |
|---|---|---|
| 個別銘柄の指値 | 都度 | テクニカル変化に応じて |
| セクター上限 | 四半期ごと | 市場のセクター循環状況 |
| VIX閾値（28） | 半年ごと | 過去6ヶ月のVIX分布 |
| 損切りライン（-7%）| 半年ごと | 過去6ヶ月の損切り発動頻度 |
| ユニバース定義 | 年1回 | TOPIX/S&P構成見直しに合わせて |

### 11-2. 運用記録の必須項目

| 記録項目 | 内容 |
|---|---|
| エントリー記録 | 銘柄、指値、約定価格、約定日、エントリー理由（5-1/5-2）|
| ポジション管理 | 撤退条件テンプレ、保有期間、含み損益推移 |
| 決済記録 | 決済価格、決済理由（損切り/利確/トレーリング）、損益率 |
| 月次集計 | 勝率、平均利益率、平均損失率、ペイオフレシオ |

### 11-3. 改訂トリガー

以下のいずれかが発生した場合、定義書の改訂を検討する：

- 月間損失が総資金の-3%超
- 3ヶ月連続で勝率が40%未満
- 市場環境の構造変化（政策金利の急変、地政学リスクの顕在化等）
- 同じパターンで3回以上の損切り発動

## 付録A：v3.1の核心理念

1. **規律 > 機会**：ルールに反する機会は見送る勇気を持つ
2. **休むも相場**：「やらない」を選べることが上級者の証
3. **数字は仮置き**：閾値は初期値、運用結果でチューニング
4. **判定の透明性**：曖昧な「例外」を作らず、明確な3段階評価で判定
5. **撤退の事前定義**：エントリー時点で撤退条件を決めておく

## 付録B：判定実践のケーススタディ（2026年5月17日の整理結果）

12銘柄判定の結果、明確なパターンが出現した：

| カテゴリ | 銘柄 | 判定 | 理由 |
|---|---|---|---|

| 🟡 条件付き適合 | 伊藤忠商事(8001) | 残す | 反転初動型、指値三重サポート |
| 🟡 条件付き適合 | 荏原製作所(6361) | 指値修正 | エントリー条件未達→修正で対応 |
| 🟡 条件付き適合 | クボタ(6326) | 指値修正 | 過熱組み合わせ該当→引き下げ対応 |
| 🔴 不適合 | 電源開発(9513) | 取消 | ユニバース外、過熱圏 |
| 🔴 不適合 | 東京センチュリー(8439) | 取消 | ユニバース外、噴き上げ急落 |
| 🔴 不適合 | 加賀電子(8154) | 取消 | ユニバース外、流動性不足 |

| 🔴 不適合 | 三菱瓦斯化学(4182) | 取消 | ユニバース外、ダブルトップ形成 |

**学び**：
- ユニバース基準（時価総額2兆円・Core30/Large70）が機能した
- 過熱組み合わせ条件（RSI65×乖離5%）が新たな高値掴みを防いだ
- 「条件付き適合」を取り入れることで、機械的取消ではなく指値修正という第三の道が確保できた
