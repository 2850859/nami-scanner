## 1. 基本戦略の考え方

中期上昇トレンドにある大型優良株に対し、**短期的な押し目で仕込み、トレンド継続を取りに行く**順張り戦略。スクリーニング（候補抽出）とエントリータイミングを分離して定義する。

- **時間足**：日足（Daily）
- **対象市場**：日本株（JP）、米国株（US）
- **想定資金規模**：1億円〜

## 2. 市場環境フィルタ（v3.0で追加・v3.1で強化）

### 2-1. 市場トレンドフィルタ（必須）

新規エントリーは、所属市場が上昇トレンドにある場合のみ実行する。

| 市場 | 基準指数 | 条件 |
|---|---|---|
| 日本株 | TOPIX | TOPIX終値 > TOPIX SMA(20) |
| 米国株 | S&P 500 (SPY) | SPY終値 > SPY SMA(20) |

**基準を満たさない場合**：既存ポジションは継続、**新規エントリー停止**。

### 2-2. ボラティリティフィルタ（必須）

| 指標 | 基準 | アクション |
|---|---|---|
| VIX | **28未満** | 通常運用 |
| VIX | **28以上35未満** | 新規エントリー停止、既存ポジションのみ継続 |
| VIX | **35以上** | 新規エントリー停止＋既存ポジションの利確検討 |

### 2-3. イベントフィルタ（必須）🆕 **v3.2: R案 実装済み**

| 状況 | アクション |
|---|---|
| 決算3営業日前〜決算翌営業日 | 該当銘柄は新規エントリー禁止（**バックテストエンジン自動制御**）|
| FOMC・日銀政策決定会合の前営業日 | 新規エントリー慎重化（指値は浅く） |
| 米雇用統計・CPI発表前日 | 同上 |

**実装詳細**：
- yfinance `.calendar` から各銘柄の次回決算日を取得
- 決算日を基点に `earnings_blackout_before=3`（前）、`earnings_blackout_after=1`（後）日をブロック
- 対象：US銘柄のみ（JP株はAPIで取得困難なため手動管理）
- パラメータ：`StrategyConfig.use_earnings_blackout` で ON/OFF 切替可能

## 3. スクリーニング条件（候補銘柄の抽出）

### 3-1. トレンド条件（必須）

- SMA(5) > SMA(10) > SMA(20)（上昇のパーフェクトオーダー）
- SMA(20) > SMA(60)（中期トレンドも上向き）
- 終値 > SMA(60)（中期トレンド上にあること）

### 3-2. 過熱感フィルタ（必須）

- RSI(14)：**40〜75**の範囲内
- 終値のSMA(20)からの乖離率：**+7%未満**
- 過熱組み合わせ除外：「RSI 65〜75」かつ「乖離率 +5%超」の組み合わせは過熱圏とみなし除外

### 3-3. 流動性条件（必須）

| 市場 | 基準 |
|---|---|
| 日本株 | 直近30日平均売買代金 **50億円以上** |
| 米国株 | 直近30日平均売買代金 **5億ドル以上** |

### 3-4. 出来高収縮フィルタ（必須）🆕 **v3.2: P案 新規追加**

押し目エントリーが「本物の押し目」であることを確認するため、エントリー候補日の出来高を確認する。

| 条件 | 内容 |
|---|---|
| 押し目日の出来高 | 直近20日間の平均出来高の **90%未満**であること |

**意図**：出来高が急増している押し目は、機関投資家の売り圧力や悪材料を反映している可能性が高い。出来高が静かに低下している押し目のみを本物の調整とみなす。

**実装パラメータ**：
- `use_volume_contraction_entry = True`（デフォルト有効）
- `volume_contraction_lookback = 20`（平均算出日数）
- `volume_contraction_ratio = 0.9`（平均の何倍未満か）

## 4. 対象銘柄ユニバース

### 4-1. 日本市場

- 時価総額 **2兆円以上**
- 客観基準：**TOPIX Core30 + TOPIX Large70** の構成銘柄を母集団とする（JPX400）
- 実行コマンド：`--universe jpx400`

### 4-2. 米国市場 🆕 **v3.2: Q案 実装済み**

- 時価総額 **2,000億ドル以上**
- 客観基準：**S&P 100** の構成銘柄を母集団とする（セクターは限定しない）
- 実行コマンド：**`--universe sp100`**（v3.2より正式採用。v3.1まで使用していた `sp500` から変更）
- 構成銘柄例：NVIDIA(NVDA)、Microsoft(MSFT)、Apple(AAPL)、Amazon(AMZN)、Meta(META) など101銘柄

**変更理由**：S&P500（500銘柄）から S&P100（超大型株101銘柄）に絞ることで、
流動性・安定性が向上し、決算日データ取得も高速化。

## 5. エントリー条件（タイミング判定）

スクリーニングを通過した銘柄に対し、以下のいずれかを満たした時点でエントリー候補とする。

### 5-1. 押し目パターン（優先）

- 終値が **SMA(5)を一時的に下抜けた後、再度終値ベースで上抜けた日**
- または、終値が **SMA(10)±1%以内にタッチして陽線で反発**した日

### 5-2. 浅押しパターン

- 終値が SMA(5) の上にあり、かつ SMA(5) からの乖離が **+2%以内**
- 直前2〜3営業日が陰線または小幅な調整局面であること

### 5-3. 指値の置き方

- 成行は使わない
- SMA(5) または SMA(10) の現値、もしくは直近3〜5営業日の安値を目安に指値
- **指値変更による追いかけ禁止**：押し目に到達せず上昇した場合、指値を上方修正してはならない

## 6. 資金管理・リスク管理

### 6-1. ポジションサイジング

- 1銘柄あたりの投入額：総資金の **10〜15%以下**
- 同時保有銘柄数：**3〜6銘柄**を目安に分散

### 6-2. セクター集中の上限（v3.0で細分化）

| セクター | 上限（総資金比） |
|---|---|
| 半導体・半導体製造装置 | 25% |
| 電線・電力インフラ | 15% |
| 防衛・重工 | 15% |
| 金融（銀行・証券・保険）| 20% |
| 商社 | 15% |
| その他単一セクター | 15% |

**合計で総資金の80%以下**（残り20%は現金または分散用バッファ）。

### 6-3. ポートフォリオ・カテゴリ分散（v3.1で追加）

銘柄を以下の2カテゴリに分類し、配分を管理する。

| カテゴリ | 定義 | 推奨配分 |
|---|---|---|
| **強トレンド型** | SMA(60)上向き、週足MACDプラス圏、明確な上昇継続中 | **60〜80%** |
| **反転初動型** | SMA(60)横ばい〜下向きから反発中、週足MACD改善中 | **20〜40%** |

### 6-4. 損切り基準（いずれか先に到達した時点で執行）

| 条件 | 内容 |
|---|---|
| ① テクニカル | 終値ベースで **SMA(20)を明確に下抜け**（1%以上の下抜けを目安）|
| ② 価格 | エントリー価格から **-7%** |
| ③ トレンド転換 | パーフェクトオーダーが崩れた（SMA(5) < SMA(10)）翌日の寄り |

**US株のみの特例**：パーフェクトオーダー崩壊が3営業日継続した場合に発動（一時的な崩れを許容）

### 6-5. 利確・トレーリング

- 含み益が **+10%** に到達した時点で建値に逆指値を移動（コスト割れ防止）
- それ以降は **SMA(10)割れ**でトレーリング決済
- RSI(14)が過熱した場合は半利確
  - 超大型株（時価総額10兆円超）：**RSI 80超**で半利確
  - 中型〜大型株（時価総額2〜10兆円）：**RSI 72〜75超**で半利確

### 6-6. 月次損失上限（v3.2: M案 実装済み）🆕

| 条件 | アクション |
|---|---|
| 月間損失が総資金の **−3%超** | 当月の新規エントリーを全て停止（既存ポジションは継続）|
| 翌月初日 | 制限を解除し通常運用を再開 |

**実装パラメータ**：
- `use_monthly_loss_limit = True`（デフォルト有効）
- `monthly_loss_limit_pct = 0.03`（3%）

### 6-7. 連続損失後のサイズ縮小（v3.1: L案 実装済み）

| 条件 | アクション |
|---|---|
| 直近3連敗以上 | 次のエントリーのポジションサイズを通常の **50%** に縮小 |
| 勝ちトレードで復帰 | 翌エントリーからサイズを通常に戻す |

## 7. 撤退条件テンプレート（v3.1で追加）

各銘柄でエントリー時に、以下の3条件を明確化する。

### 7-1. 撤退条件テンプレ

```
銘柄：____________ (コード ____________)
エントリー指値：____________円
エントリー時の関連数値：
  - SMA(20)：____________円
  - 直近のサポートライン：____________円

撤退条件①：終値が SMA(20) を明確に下抜け（____________円割れ）
撤退条件②：エントリー価格から -7%（____________円）
撤退条件③：パーフェクトオーダー崩壊（SMA(5) < SMA(10)）
追いかけ禁止：指値到達せず上昇した場合、指値を上方修正しない
```

### 7-2. 特殊カテゴリ向け追加条件

**反転初動型銘柄**は通常の3条件に加え、以下を併用：
- 撤退条件④：直近の反発基点を割り込んだ場合（例：直近安値が1,950円なら1,940円割れで撤退）

## 8. 判定の透明性ルール（v3.1で追加）

スクリーニング・エントリー条件で**明確に判定が分かれた場合**の扱いを定義する。

### 8-1. 条件適合の3段階評価

| 評価 | 条件 | 推奨アクション |
|---|---|---|
| 🟢 完全適合 | スクリーニング全項目クリア＋エントリー条件該当 | 通常エントリー |
| 🟡 条件付き適合 | スクリーニング全項目クリアだが、エントリー条件未達 | **指値修正で対応** |
| 🔴 不適合 | スクリーニング項目に1つでも不合格 | **エントリー禁止・取消** |

### 8-2. 判定ログの記録（必須）

```
日付：____________
銘柄：____________ (____________)
判定：🟢 / 🟡 / 🔴
不合格項目：____________
アクション：エントリー / 指値修正（旧:_____ → 新:_____）/ 取消
備考：____________
```

## 9. 「やらない局面」リスト（v3.1で追加）

### 9-1. 市場全体での停止条件

| 状況 | 停止期間 |
|---|---|
| TOPIX終値 < SMA(20) | 復帰まで |
| SPY終値 < SMA(20) | 復帰まで（US株のみ） |
| VIX ≥ 28 | 復帰まで |
| FOMC・日銀会合の翌営業日まで | イベント通過まで |
| 米雇用統計・CPI発表当日 | 発表後の落ち着きまで |

### 9-2. 個別銘柄での停止条件

| 状況 | 停止期間 |
|---|---|
| 決算3営業日前〜決算翌営業日 | 期間中（**バックテストエンジン自動制御**）|
| 重要IR発表予定 | 発表翌営業日まで |
| 出来高急増（直近平均の3倍超）翌日 | 出来高が落ち着くまで（最低3営業日）|
| 押し目日の出来高が平均×0.9以上 | エントリー不可（**出来高収縮フィルタ**）|

### 9-3. 自分の状態での停止条件

| 状況 | 対処 |
|---|---|
| 直近3トレード連続で損切り | ポジションサイズを50%に縮小（**自動制御**）|
| 月間損失が総資金の-3%超 | その月の新規停止（**バックテストエンジン自動制御**）|
| 感情的になっている（怒り・焦り・興奮）| 24時間休む |
| 睡眠不足・体調不良 | 回復まで休む |

```
【依頼内容】

   と明示し、最も惜しい銘柄を3件、未達条件と併記して提示
```

## 付録A：v3.2の核心理念

1. **規律 > 機会**：ルールに反する機会は見送る勇気を持つ
2. **休むも相場**：「やらない」を選べることが上級者の証
3. **数字は仮置き**：閾値は初期値、運用結果でチューニング
4. **判定の透明性**：曖昧な「例外」を作らず、明確な3段階評価で判定
5. **撤退の事前定義**：エントリー時点で撤退条件を決めておく
6. **自動制御と手動判断の分離**：決算回避・月次制限・連続損失縮小はエンジンが自動制御、FOMC等のマクロイベント判断は人間が行う

## 付録B：バックテストエンジン実装パラメータ一覧（v3.2時点）

| `use_volume_contraction_entry` | True | 出来高収縮フィルタ有効化 |
| `volume_contraction_lookback` | 20 | 出来高平均算出日数 |
| `volume_contraction_ratio` | 0.9 | 平均出来高の何倍未満か |
| `use_monthly_loss_limit` | True | 月次損失上限有効化 |
| `monthly_loss_limit_pct` | 0.03 | 月間損失上限（3%） |
