第5回課題｜波乗りスキャナー × YouTube連動

「ツールで、どんな課題を解決したいか」を言語化した結果と、実装したソリューションの設計図です。

grill-me 実施済み ペイン構成あり YouTube API Gemini AI GitHub Actions

1. grill-me の結果（課題の言語化）

グループセッションで話す1文
毎日5つの投資チャンネルを追うのが漏れやすく判断に自信が持てなかった。波乗りスキャナーに YouTube字幕要約＋波乗りルールとの矛盾アラート を組み合わせることで、メール1通で売買判断が完結する仕組みを作った。
  1. 受益者：自分だけ（個人の投資判断サポート）
  2. 解決する痛み：複数チャンネルの情報収集の漏れ＋判断基準のなさ
  3. 連動の形：毎朝のスキャンメールに「昨日の各チャンネル更新サマリー」を追記
  4. 要約の深さ：タイトル＋自動字幕をGeminiで3〜5行に要約
  5. 矛盾フラグ：波乗りシステムのルール（system_spec.md）を基準にAIが警告マーク
  6. 成功の定義：メール1通で判断材料が揃い（見落としゼロ＋追加調査不要）

3. ソリューション設計

成功の定義
メール1通を読むだけで、スキャン結果＋5チャンネルの最新要約＋矛盾アラートが確認でき、追加調査ゼロで当日の売買判断に臨める。かつ、どのチャンネルの更新も見落とさない。

データフロー（新旧の関係）

矛盾アラートのイメージ

メール内に自動生成されるアラートの例

矛盾 CLEARTRADEチャンネル — 「押し目は10%以上待て」
波乗りルールは押し目 1.0〜1.5×ATR（約3〜5%相当）のため、深すぎる待機は波乗り戦略と合わない可能性。
一致 波乗りチャート向川チャンネル — 「MA5が20日線上で維持されていることが条件」
波乗りルールのトレンドフィルター T1・T2 と合致しています。
