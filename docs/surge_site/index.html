背景

そもそも波乗りスキャナーとは？

株を知らない方向けに、身近なたとえで説明します。

Amazonの絞り込みフィルター、の株版

Amazonで「3,000円以下・評価4.5以上・在庫あり・翌日配送」と絞り込むように、約4,000銘柄の株を毎日自動でフィルタリングします。

ゴールデンクロスとは

「短期の平均価格」が「長期の平均価格」を下から上に突き抜けた瞬間。
波に乗り始めるタイミングを示す信号です。

まとめ：スキャナーは「今日、波に乗り始めそうな銘柄を自動で見つけ、朝メールで教えてくれる」ツールです。ヤフーファイナンスのデータを使って毎日自動で動きます。

ソリューション

どう解決するか — 新しい仕組み

成功の定義：メール1通を読むだけで、スキャン結果 + 5チャンネルの最新要約 + 矛盾アラートが確認でき、追加調査ゼロで当日の売買判断に臨める。かつ、どのチャンネルの更新も見落とさない。

システム全体のデータフロー

矛盾アラートの仕組み

「波乗りシステムのルール」をAIに覚えさせ、各チャンネルの主張が食い違う場合に警告を出します。

アラートの例（メール内のイメージ）

矛盾 CLEARTRADEチャンネル —「押し目は10%以上待て」
波乗りルールは押し目 1.0〜1.5×ATR（約3〜5%相当）のため、深すぎる待機は波乗り戦略と合わない可能性があります。
一致 波乗りチャート向川チャンネル —「MA5が20日線上で維持されていることが条件」
波乗りルールのトレンドフィルター T1・T2 と合致しています。
