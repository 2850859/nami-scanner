# 課題提出：面倒な報告を自動化するツール（波乗りスキャナー／売買仕様）

**コース**: AI-Driven School  
**教材タイトル（参考）**: 面倒な報告を自動化するツールを作る  
**提出物**: 本ドキュメント（リポジトリ `nami-scanner` に基づく仕様・自動化の説明）

---

## 1. 課題で求められる「報告の自動化」と自分のツールの対応

| 面倒になりがちな「報告」 | このツールでの自動化 |
|--------------------------|----------------------|
| 毎日、JPX400／S&P500 を見てゴールデンクロスや強い銘柄を探す | Python で `scan_jpx400.py` / `scan_sp500.py` が一覧化し、`results/*.json` に保存 |
| 結果をメールや資料にまとめる | `send_mail.py` が CSV 添付メールで配信（GitHub Actions と連携可） |
| GC（ゴールデンクロス）発生後の勝ち負けを手で追う | `track_gc.py` が `data/gc_tracker.csv` 等に蓄積 |
| 売買ルールを言葉だけで終わらせ、検証できない | `trade_rules/backtest_engine.py` でルールをコード化し、`run_cleartrade_yfinance.py` でバックテストと CSV 出力 |

**一言まとめ**: 「毎日の銘柄チェックと報告・記録」を、**スキャン → JSON → メール／蓄積 →（任意）バックテスト**の流れで自動化する。

---

## 2. ツール全体の流れ（だれが何をするか）

1. **開発者・あなた**: 一度ルールとスクリプトを用意する（このリポジトリ）。
2. **GitHub Actions（任意）**: 平日に決まった時刻にスキャンやメールを実行。
3. **受け手**: メールで当日のシグナル一覧（CSV）や画面キャプチャを受け取る。

## 3. 波乗り × cleartrade「売買・検証」仕様（要約）

詳細はリポジトリ内 `trade_rules/SYSTEM_SPEC.md` に全文あり。ここでは提出用に要点だけ記載する。

### 3.1 対象銘柄のイメージ（ユニバース）

- 東証プライム／スタンダード想定、時価総額・売買代金の下限あり（仕様書 §1）。

### 3.2 スクリーニング（すべて満たす）

- 出来高急増、20 日高値ブレイク、20 日モメンタム、株価と TOPIX がそれぞれ 20 日線上、など（§2〜3）。

### 3.3 押し目・エントリー（実装では改善版あり）

- **既定**: ATR(14) を使い、過去 10 日高値からの下落幅が **約 1.0〜1.5×ATR** のゾーンを押し目とみなす（§13.1）。
- **エントリートリガー**: 前日高値ブレイク **または** 陽線包み足に加え、**出来高が前日比 +20% 以上** など（§13.2）。
- **エントリー価格の比較**: 翌寄り／当日引け／翌日 VWAP 代理、をバックテストで比較可能（§13.3）。

### 3.4 イグジット（改善版）

- 損切り: 終値がエントリー −5% 以下、**または** 押し目形成区間の最安値を終値が下回る、など（§13.4）。
- 利確: 高値が +10% に達したら半分利確。残りは **終値が 5 日線を下回ったら** 全決済。**最大 15 営業日**で強制決済。

### 3.5 日次スキャナーとの連携

- `scan_jpx400.py` の日足結果に、`trade_rules_candidate`・ランク再計算などを付与（§13.6）。

## 4. 自動化の「動き」（コマンド・ファイル）

| 目的 | コマンド例（プロジェクトフォルダで実行） |
|------|------------------------------------------|
| 単体テスト | `python -m pytest tests/ -v` |
| バックテスト（例） | `python -m trade_rules.run_cleartrade_yfinance --tickers 7203.T --period 3y --out-dir results` |
| テストメール | `python send_mail.py --test`（要: 環境変数 `RESEND_API_KEY`, `NOTIFY_EMAIL`） |

成果物の例: `results/*.csv`、`results/cleartrade_backtest.json`、メール添付 CSV。
