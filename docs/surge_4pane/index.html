チャンネル間の矛盾に気づかない
★★☆ ·判断時· 未解決

矛盾アラートの実例（メール内イメージ）

矛盾 CLEARTRADEチャンネル — 「押し目は10%以上待て」
波乗りルールは1.0〜1.5×ATR（約3〜5%相当）のため、深すぎる待機は戦略と合わない可能性。
一致 波乗りチャート向川 — 「MA5が20日線上で維持されていることが条件」
波乗りルールのトレンドフィルター T1・T2 と合致しています。

仕組み

Gemini AI が各チャンネルの字幕内容を system_spec.md（波乗りルール） と照合し、明確に相反する主張がある場合に警告を自動付与します。

波乗りルールと違う手法を混ぜてしまう
★★☆ ·エントリー時· 未解決

波乗りシステム 主要ルール（比較基準）

条件内容
スクリーニング出来高急増 / 高値ブレイク / モメンタム（3条件AND）
トレンドフィルター銘柄終値 > MA20 / TOPIX終値 > MA20
押し目ATR(14) × 1.0〜1.5（約3〜5%）
エントリー高値ブレイク or 包み足 + 出来高再拡大
損切り終値 ≤ エントリー × 0.95

矛盾フラグの効果

AIが各チャンネルの主張をルールと照合して警告を出すため、「Aチャンネルが言っていたから」という感覚的な判断を防ぐことができます。

Gemini AI 要約 + 矛盾フラグ
新規追加 ·Gemini 2.0 Flash

プロンプト設計

Gemini に「波乗りシステムのルール（system_spec.md）」を渡し、各動画の内容を要約させながら、ルールとの矛盾を自動検出させます。

入力: タイトル + 字幕テキスト + system_spec.md
出力: { "summary": "3〜5行の要約", "conflict": true/false, "conflict_detail": "..." }

出力例

conflict: true
押し目について波乗りルール（1〜1.5×ATR）と異なる主張あり
conflict: false
波乗りルールとの矛盾なし。MA5・出来高条件の解説で一致。
